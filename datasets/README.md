# Dataset placement

Raw datasets are not included in this repository.

Place OULAD files under:

```text
datasets/raw/oulad/
```

Required OULAD files:

```text
studentInfo.csv
studentVle.csv
studentAssessment.csv
assessments.csv
vle.csv
```

Place the original UCI student dropout/success CSV under:

```text
datasets/raw/uci_dropout_success/
```

The UCI file must contain the `Target` column. Summary files such as target-distribution tables are not required as inputs.
